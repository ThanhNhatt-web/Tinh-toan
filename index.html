Đổi MiB ⇄ số N

File ghi các số từ 1 tới N, mỗi số một dòng, mã hóa ASCII/UTF-8, xuống dòng kiểu LF (Linux). Tính chính xác, không làm tròn.

S(N) = (d + 1) × N + d − (10^d − 1) / 9 (byte, d = số chữ số của N) MiB = S(N) / 1.048.576 N = (B − d + (10^d − 1) / 9) / (d + 1), B = MiB × 1.048.576
